# Документация проекта

Эта директория содержит проектную документацию backend в чистом и презентационном виде.

На текущем этапе в backend реализован API-сценарий создания пациента врачом: врач создает карточку пациента из своего региона, система назначает пациенту обезличенный код для входа и одноразово выдает временный пароль.

Доступ к backend API-маршрутам создания и списка пациентов защищен через Spring Security: запрос должен быть аутентифицирован, пользователь должен иметь роль `DOCTOR`, а backend определяет профиль врача по текущей учетной записи. Список пациентов определяется по региону врача, без прямой привязки пациента к конкретному врачу.

Реализованные backend маршруты:

- `POST /api/doctor/patients` — создание карточки пациента врачом
- `GET /api/doctor/patients` — список пациентов региона врача
- `GET /api/patients/{id}` — получение карточки пациента с role-based уровнем детализации
