# Документация по endpoint-ам пациентов

## Назначение

Backend поддерживает сценарий, в котором врач создает карточку пациента, а затем получает список пациентов своего региона.

Самостоятельная регистрация пациента в текущем API не предусмотрена.

## Маршруты

### `POST /api/doctor/patients`

Создает карточку пациента от имени врача.

Что делает endpoint:

- принимает медицинские данные пациента;
- проверяет, что запрос выполняет аутентифицированный врач;
- определяет профиль врача по текущей учетной записи;
- определяет регион пациента по региону врача;
- создает учетную запись пациента;
- генерирует обезличенный код пациента;
- использует этот код как логин пациента;
- генерирует временный пароль;
- сохраняет карточку пациента.

Основные поля запроса:

- `age`
- `diagnosis`
- `valve.name`
- `valve.size`
- `valve.material`
- `operationParameters.anesthesia`
- `operationParameters.durationMinutes`
- `operationParameters.deliverySystem`
- `medications`

Что возвращает:

- `id`
- `patientCode`
- `temporaryPassword`
- сохраненные данные карточки пациента

### `GET /api/doctor/patients`

Возвращает список пациентов региона врача.

Что делает endpoint:

- проверяет аутентификацию пользователя;
- проверяет роль `DOCTOR`;
- определяет профиль врача по текущей учетной записи;
- возвращает пациентов региона врача без прямой привязки пациента к конкретному врачу.

## Ограничения доступа

- пациент не может создать карточку самостоятельно;
- пациент не может вызывать doctor endpoint для создания карточки;
- врач не может создать пациента в другом регионе;
- врач видит пациентов по своему региону, а не по прямому владению карточкой.
